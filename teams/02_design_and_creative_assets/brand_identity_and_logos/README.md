## 1. Master Logo Variants (The 4 Canonical Forms)

```
┌─────────────────────────┐  ┌─────────────────────────┐  ┌─────────────────────────┐  ┌─────────────────────────┐
│       VARIANT A         │  │       VARIANT B         │  │       VARIANT C         │  │       VARIANT D         │
│       Dark Logo         │  │       Light Logo        │  │      Monochrome         │  │       Icon-Only         │
│   (Black Canvas #050505)│  │   (White Canvas #FFFFFF)│  │ (Pure Black / Pure White│  │  (Secondary Brand Mark) │

```

| Variant | Canvas / Background | Artwork Description & Composition | Primary Application |
|---|---|---|---|
| **Variant A: Dark** | Void Black (`#050505` / `#000000`) | Bold Astral White typography with Electric Violet (`#A855F7`) glowing accents and orbital comet sweep | Primary format: Dark mode website hero, main stage 4K LED wall, hoodies, roll-up standees. |
| **Variant B: Light** | Crisp Pure White (`#FFFFFF`) | Dense Black typography with Electric Violet / Deep Orchid accents | Official institutional proposals, vice-chancellor approvals, press releases, white paper prints. |
| **Variant C: Monochrome** | Pure Black OR Pure White | 100% solid Black silhouette (for white media) or 100% solid White reverse (for dark media) | Laser etching on anodized aluminum smart badges, wax seals, single-color silkscreen apparel. |
| **Variant D: Icon-Only** | Any approved background | Standalone Celestial Hourglass mark (No `KAIROS` text, No `SBG` text) | Favicon, app launcher, Discord avatar, WhatsApp icon, chest embroidery, countdown graphics. |

### ⚠️ Evergreen Logo Mandate
The circular KAIROS logo is strictly **evergreen**. Do not embed *"48-HOUR HACKATHON"* inside the circular badge border. The circular mark contains only the outer rings, `K A I R O S` arch, central celestial hourglass with planetary orbit, and the base arch `AWS STUDENT BUILDER GROUP SATHYABAMA`. All specific event descriptors belong on supporting collateral.

## 4. The 5 Core Visual Motifs

1. ⏳ **Time:** The Celestial Hourglass — time as a focused vector of creation.
2. ✦ **Innovation:** Four-Point Sparkle Star — representing technical breakthroughs and deploy milestones.
3. ◯ **Movement:** Elliptical Planetary Ring — distributed microservices and multi-agent systems orbiting the core.
4. • **Progress:** Descending Stardust Sand Beads — the ticking sprint of ideas turning into working code.
5. → **Momentum:** Sweeping Orbital Comet Tail — continuous forward acceleration from idea to deployment.

Together, these form the KAIROS builder journey: **`Time → Idea → Build → Ship`**.
