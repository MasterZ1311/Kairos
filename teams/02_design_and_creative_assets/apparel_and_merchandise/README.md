## 2. The KAIROS T-Shirt System (3 Curated Options)

Rather than placing a simple logo in the center, KAIROS implements a dynamic **front + back graphic architecture** tailored for distinct developer aesthetics:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      THE 3-TIER T-SHIRT ARCHITECTURE                   │
├────────────────────────────────────────────────────────────────────────┤
│ OPTION A: MINIMAL STREETWEAR                                           │
│ • Front: Small celestial hourglass icon + "KAIROS" on left chest       │
│ • Back:  Large circular evergreen KAIROS logo with orbital ring        │
├────────────────────────────────────────────────────────────────────────┤
│ OPTION B: HACKER AESTHETIC                                             │
│ • Front: "KAIROS" + digital terminal timer "48:00:00"                  │
│ • Back:  Massive distressed hourglass accompanied by:                 │
│          "BUILD BEFORE TIME RUNS OUT."                                 │
├────────────────────────────────────────────────────────────────────────┤
│ OPTION C: TEAM & ORGANIZER SHIRT                                       │
│ • Front: "KAIROS" + "AWS STUDENT BUILDER GROUP"                        │
│ • Back:  The 48-Hour Sprint Arc:                                       │
│          "48 HOURS → IDEA → BUILD → SHIP"                              │
└────────────────────────────────────────────────────────────────────────┘
```

### Technical Fabric & Print Specifications:
* **Fabric:** 180 GSM Ring-Spun Super-Combed Dry-Fit Poly-Cotton (Breathable, moisture-wicking for continuous 48-hour hacking).
* **Colorway:** Deep Void Black (`#000000`).
* **Printing Technology:** Direct-to-Film (DTF) multi-color elastomeric transfer with ultra-soft hand-feel.
* **Total Units:** 550 Units (Allocated across Options A, B, and C based on participant preference and role).
